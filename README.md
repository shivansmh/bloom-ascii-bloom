# Bloom Ascii Bloom

I want to build a portfolio website for myself. I need an aesthetic and minimalistic dark background with a primary ascii art lily on it which is interactive (it spreads outerwards wherever the cursor is). It has some space on the left for the text i will put in big fonts and put the lily in the right. just a single no scroll page.
